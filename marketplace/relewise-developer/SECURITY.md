# Security

Relewise Developer connects to the public Relewise Developer MCP server at `https://mcp.relewise.com`.

- No Agent Gateway Personal Access Token is required.
- Do not include customer data, application secrets, or production credentials in prompts or test submissions.
- Review generated code before using it in a production integration and keep work under source control.
- The AI host's own data-handling and privacy terms also apply.

Report suspected vulnerabilities privately to [support@relewise.com](mailto:support@relewise.com).
